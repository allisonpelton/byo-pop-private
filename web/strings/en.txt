# byo-pop's text: every word the site shows, in one place (docs/WEB_PLAYER.md, "The site's text").
#
# One string a line: key = text. A long string can go on over the next lines: a line that starts with spaces is joined to
# the one before it with a single space. Lines that start with # are notes, and blank lines are skipped.
#
#   {name}    filled in by the page: a game's title, a number, a date. Keep each one the string has; move it freely.
#   a | b     a string that counts something ({n}): the text for one, then the text for any other number.
#   _html     a key that ends in _html holds markup (links, <code>, <strong>): keep its tags whole.
#
# Change the text freely; keep the keys. A key the site asks for and this file lacks stops the build, so a key can't be
# lost by accident. Rebuild the site (tools/check.sh build-web) to see a change.
#
# The terms (web/terms.html) and the licences are not here: they stay word for word as written.
