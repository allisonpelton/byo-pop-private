Replays

With the replays mod on, every finished game is kept here (the newest few, and every one that made a high-score table). Import a .bjr file to watch someone else's game. The game lists them too (Options, Extras, Replays...). While one plays, Space or a click pauses, 1 to 4 set the speed (up to 8x), N plays to the next move and Esc goes back to your game, which is offered again.
