# Bonnie's Bookstore Deluxe: every screen and dialog

One row for each screen or dialog the game can show (`docs/SHOTDIFF.md`, "Every screen, listed"), from `game/Screens.h`, `game/GameScreen.cpp` and the dialogs they call. The shots are pairs of the newest shotdiff run: the original under origrun in Windows Sandbox against the port with `-fast -seed=1`, windowed (the game has no 3D mode and one size; its Full Screen option draws the same 800x600 picture). `tools/screens/` has the scripts that reach them; `IDENTICAL_PLAY.md`, "The screen coverage pass", tells how.
