# Bookworm Adventures: every screen and dialog

This is the game's list of every screen and dialog it can show (`docs/SHOTDIFF.md`, "Every screen, listed"). It is taken
from the port's source (`src/`, each class and dialog id), the export it was translated from, and the game's scripts,
which draw most of the adventure and open most of its dialogs (`tools/luc.py dis` on the staged scripts: every call of
`DoGenericDialog`, `DoYesNoDialog` and `DoArenaWinDialog`). The comparison that takes each row's shots is the
screenshot pilot (`tools/pilot/`, `IDENTICAL_PLAY.md`). Each part is one list of steps that both sides play, the port
under rundesk. In 2D the original runs on the host through origrun's in-game frame reader, but for two parts that run
in Windows Sandbox: the new player's (its intro is a Flash movie on its own timers) and full screen (whose original
shots are windowed: the sandbox's 2D original takes no full screen).

A shot named `x` is a 2D pair, and `x_full` one taken with the registry set to full screen. A clip is a folder of
frames. All of them are pairs in the game's newest shotdiff run (`build/shotreview/bookwormadv/<run>/summary.json`).
The run's id is in `IDENTICAL_PLAY.md`, "Every screen (2026-11-22)", which also says how the parts ran and why the
pairs differ where they do. A row's note says "explained" where its pairs differ visibly. The 3D pairs (`x_3d`) come
in once the 3D parts have run again.
